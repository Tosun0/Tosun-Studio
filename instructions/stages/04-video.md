# Stage 04 — Video

영상 생성 요청은 장면별로 분리합니다. 승인된 이미지와 영상 프롬프트를 기준으로 카메라, 동작, 시간 흐름, 전환을 확인합니다. 외부 provider가 비동기이면 job id와 요청 시각을 기록하고, 완료 응답과 실제 로컬 파일 또는 호스팅된 영상 결과를 받은 경우에만 생성 완료로 처리합니다. 실제 비디오를 표시한 뒤 사용자의 승인을 기다립니다.

화자·대사·발화 시간 점검, 모델과 비용, 실패 후 재시도와 검증 기준은 `plugins/tosun-studio/skills/03-video/SKILL.md`를 따릅니다. 사용자가 직접 검증하기로 했다면 재제작에도 그 선택을 유지하고 `not_run`으로 기록합니다. 생성 완료와 화자·대사 검증 완료는 구분합니다.
