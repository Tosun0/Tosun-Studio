# Stage 04 — Video

영상 생성 요청은 장면별로 분리합니다. 승인된 이미지와 영상 프롬프트를 기준으로 카메라, 동작, 시간 흐름, 전환을 확인합니다. 외부 provider가 비동기이면 job id와 요청 시각을 기록하고, 파일이 실제로 존재할 때만 완료 처리합니다. 실제 비디오를 표시한 뒤 사용자의 승인을 기다립니다.

모델 선택과 비용 확인은 `plugins/tosun-studio/skills/03-video/SKILL.md`를 따릅니다. 기본 모델은 Kling 3.0 Pro이며, 대사가 있으면 음성을 켭니다. 생성 직전 실시간 견적을 확인하고 이미 승인된 비용 범위에서 컷당 1회 생성합니다. 출력 해상도·프레임·음성은 실제 결과로 검증합니다.
